## 方針

**実物の PostgreSQL に対して実行する。**
本システムの設計は EXCLUDE 制約・パーティション・配列型といった PostgreSQL 固有の機能に
依存しており、H2 などのインメモリ DB では再現できない。Testcontainers を用いる。

## 対象範囲

| レイヤ | 検証すること |
| --- | --- |
| 永続化 | Flyway のマイグレーションと JPA マッピングの整合、DB 制約が不正データを拒否すること |
| API | HTTP 経由でのユースケースの成立、権限による制御、エラー応答の形式 |
| シナリオ | 複数ユースケースを跨いだ業務の流れ |
