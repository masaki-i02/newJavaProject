## 1. この回で分かったこと

### 1.1 「テストがあるから守れている」は思い込みだった

ミューテーションテストを 16 回実施したところ、**多くが生存した**。
テストは 288 件すべて緑だが、緑の理由は「守れているから」ではなく
「そこを検査していないから」だった。

| 生存したミューテーション | なぜすり抜けたか |
| --- | --- |
| 法定休日を残業の累積に数える | 唯一の担当テストが「法定休日 2 時間 + 翌日 6 時間 = 8 時間」で、**閾値をまたがない**。数えても数えなくても結果が同じ |
| 法定休日の区間から深夜属性を落とす | 日曜へまたぐケースで `legalHolidayTime()` しか assert していない |
| 所定の境界で切らない | 固定時間制のテストがすべて所定 8 時間 = 法定 8 時間。**所定 < 法定 という最も普通の設定が 1 件も無い** |
| 規則の深夜帯・法定労働時間を定数に置き換える | 全テストが既定の規則 1 種類しか使っていない |
| 集計値と内訳の照合を 2 本削除 | 4 区分あるうち 2 本にしか矢を放っていない |
| 34 条の 8 時間境界を非厳密にする | 1 点しか試していない |
| ArchUnit の禁止先を 5 個から 1 個に削る | 各ルールの **1 要素しか**踏んでいない |

**閾値をまたがない数字を選んだテストは、ルールを消しても落ちない。**
これは第 2 回の落とし穴 24（正常系を 1 行にまとめない）と同型である。

### 1.2 恒真なアサーションを潰しきれていなかった

前回のコミットで 18 か所の恒真な行を外したが、**2 か所残っていた**。
どちらも `compact constructor` が強制する不変条件を不等式で書き写したもので、
破れていれば例外で落ちてアサーションに到達しない。

### 1.3 実装を直したときに設計書を戻していなかった

**3 件**見つかった。うち 1 件は、秒の丸めの欠陥を修正したあとも
設計書が「開始が切り捨て・終了が切り上げなので、逆転はしない」と書いたままで、
**修正済みの欠陥を設計書がなお正しいと主張する**状態になっていた。

同じ種類の抜けが 3 件出たので、設計規約チェックリストに 8 章
「実装を変えたとき」を追加した（落とし穴 18 の方針）。

### 1.4 法令上の規定が 2 つ丸ごと抜けていた

要件・設計・実装のどこにも存在しなかった。

- **月 60 時間超の時間外労働に対する 50% 割増**（労基法 37 条 1 項但書）。
  中小企業への猶予は 2023 年 4 月 1 日に終了している
- **法定休日から翌暦日へ及んだ労働の通算**（昭 63.3.14 基発 150 号）。
  通算しないと、例示したケースで **6 時間ぶんの 25% が支払われない**

要件定義書を版 0.4 に改訂した。いずれも月次の集計なので、実装は M1-b で行う。

### 1.5 中核の計算そのものには誤りが無かった

100 万件超のファズで、次の不変条件はいずれも違反 0 件だった。

- 内訳（基本 + 法定内 + 法定外 + 法定休日）の合計 = 実労働時間
- 休憩時間 ≥ 0、区間が重ならず時系列順、分割前後で合計が変わらない
- 分単位の独立オラクルとの 7 値一致（120,000 件で差分 0）
- 1 分未満の休憩 832,162 件で区間の重なり 0 件（落とし穴 32 の修正が効いている）

## 2. 重大な指摘と対応

| # | 指摘 | 対応 |
| --- | --- | --- |
| 1 | **出勤と退勤が同一時刻だと HTTP 500 になり、打刻が記録できない。** 拘束時間として長さ 0 の `TimeRange` を作ろうとして `IllegalArgumentException` が飛ぶ。`DomainException` ではないので Problem Details に変換されない | 拘束時間 0 分として扱う。`isClosed()` の契約違反も直した |
| 2 | **法定休日から翌暦日へ及んだ労働が通算されない**（割増の不払い） | 要件を版 0.4 に改訂。実装は月次（M1-b） |
| 3 | **月 60 時間超の 50% 割増がどこにも無い** | 同上 |
| 4 | **業務ルール違反 5 件が `DomainException` を継承していない。** API 設計書が 422 と書いている経路が 500 になる | `BusinessRuleViolationException` を新設して差し替え |
| 5 | **`daily_attendance_slices` に整合性の制約が 1 つも無い。** 無関係な `calendar_date`・暦日をまたぐ区間・重なった区間をすべて受け入れていた | `CHECK` 2 つと `EXCLUDE` を追加 |
