# 03_単体テスト

## 作成予定の文書

| 文書 | 内容 |
| --- | --- |
| 単体テスト仕様書 | テストケース一覧（ID、対象、前提条件、入力、期待結果） |
| テスト観点表 | 業務ルールごとの観点と、境界値・異常系の洗い出し |

## 方針

**テストケース ID を JUnit のテスト名に対応させる。**
仕様書とコードが乖離しないようにするための規約であり、レビュー時に
「この業務ルールのテストはどこか」を検索一発で辿れる状態にする。

| 仕様書 | コード |
| --- | --- |
| `UT-BR05-01` フレックス：総枠を超えた分が時間外になる | `@DisplayName("UT-BR05-01 ...")` |

## 対象範囲

ドメイン層の計算ロジックを主対象とする。フレームワークもデータベースも起動せずに
実行できるため、境界値を網羅的に検証できる。永続化層とコントローラは結合テストで扱う。
