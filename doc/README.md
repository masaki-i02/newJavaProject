## 文書間の追跡可能性

要件からコードまでを ID で一本に繋ぐ。仕様が変わったとき、どのテストとどのコードに
影響するかを機械的に辿れる状態を維持する。

```
要件定義書 BR-05（フレックスの時間外労働）
  ├─ 詳細設計   ドメインモデル設計書：MonthlySettlement
  ├─ 単体テスト  UT-BR05-01 〜 UT-BR05-05
  └─ 実装       FlexTimeSettlementRule（@DisplayName に BR-05 を明記）
```
